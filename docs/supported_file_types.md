# Supported file types

Out-of-the-box, you can upload the following file types:
* PDF
* JPEG
* JPG
* PNG
* TXT
* HTML
* MD (Markdown)
* DOCX
* JSON

Each file can be up to 200 MiB by default; set `AZURE_UPLOAD_MAX_BYTES` to change the limit. Large PDF and Word files (100+ pages) are supported. To synthesize them into project documentation, see [Document synthesis, export, and infographics](synthesis_and_infographics.md).
